# 🎬 Yalla Shot - منصة بث الفيديو

منصة احترافية لرفع وبث الأفلام والفيديوهات مع نظام إعلانات متكامل.

## ✨ المميزات

- 📹 تشغيل الفيديوهات بجودة عالية
- 🎥 بث مباشر للفيديوهات
- 💰 نظام إعلانات Google AdSense
- 🎨 واجهة احترافية بتصميم أسود
- 🔐 لوحة تحكم آمنة للإدارة
- 📊 إحصائيات المشاهدات
- 💬 نظام التعليقات

## 🛠️ التقنيات المستخدمة

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js + Express.js
- MongoDB
- JWT Authentication

### الإعلانات
- Google AdSense

## 📦 التثبيت والتشغيل

### 1. Frontend Setup
```bash
cd frontend
npm install
npm start
```

### 2. Backend Setup
```bash
cd backend
npm install
npm start
```

### 3. متطلبات البيئة
أنشي ملف `.env` في مجلد Backend:
```
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
GOOGLE_ADSENSE_ID=ca-pub-xxxxxxxxxxxxxxxx
```
